# sudo-get-a-job

Apply to jobs from your coding agent. A browser-control skill for Claude Code and Codex that needs **no LLM API keys**: your coding agent does the thinking, this repo gives it cheap, compact eyes and hands in your real Chrome.

> Work in progress. Built on [browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast) (MIT).
